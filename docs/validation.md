# 验证范围与发布边界

问题记录日期：2026-11-10。版本：v0.1.0-beta.1。

2026-11-10 本机结果：24 项合成回归测试通过；源码图形界面启动通过；真实本机资料的只读界面检查发现 2 个已保存账户，并成功预览合并后的 10 个本地项目，未调用同步或恢复。此项只读检查不等同于真实换号后的项目显示验收。

## 自动验证

公开测试全部使用合成账户、合成项目和临时数据库，不包含真实用户快照。

覆盖：任意数量账户发现、一源多目标、源账户不在当前登录分区、未选账户保留、项目数量与变更、源优先冲突、必须手动解决的目标冲突、显式无项目会话、重复运行、云端排序及其他私有设置保留、未知账户选择和未知迁移结构停止。

存储测试覆盖：按表结构识别数据库、中文与空格路径、确认前不写入、运行中拒绝提交、确认后文件变化停止、数据库歧义拒绝、WAL 已提交正文备份、提交失败自动回退、损坏备份拒绝恢复，以及同步和恢复前后来源数据库 SHA-256 不变。

Windows CI 对同一源码执行测试、公开文件审计和 EXE 构建，并运行 `--smoke-test`：创建图形界面后自动退出，不扫描真实账户、不修改 Codex 配置。

## 实测结果如何记录

Release 说明列明实际完成的自动检查与本机 EXE 启动检查。EXE 启动成功只证明该构建能够启动界面；不会被表述为真实账户切换、全部数据恢复或跨版本兼容验收。
